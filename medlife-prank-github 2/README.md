# MedLife — медичний антистрес 😌

Жартівливий мінісайт для студентки-медика.

## Що всередині

- випадковий «діагноз дня»
- жартівлива перевірка пульсу
- кавова шкала життєздатності
- прогноз чергування
- медичні «мудрості»
- екстрена кнопка для настрою

## Запуск локально

Просто відкрий `index.html` у браузері.

## GitHub Pages

1. Створи репозиторій на GitHub.
2. Завантаж туди `index.html`, `style.css`, `script.js`.
3. Відкрий `Settings` → `Pages`.
4. У `Build and deployment` вибери `Deploy from a branch`.
5. Обери `main` і `/root`.
6. Натисни `Save`.

Після цього GitHub видасть публічне посилання на сайт.

> Сайт створений лише для жарту й не містить медичних рекомендацій.
